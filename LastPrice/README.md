# Last Price

Starter Minecraft Java 1.20.1 Forge mod project. Requires Java 17 and GeckoLib for Forge 1.20.1.

## Build
Run `./gradlew build` (or `gradle build` where Gradle is installed). The JAR is written to `build/libs/`.

This is a starter scaffold, not yet the finished horror mod. Monster behavior, uploaded assets, structures, and custom menu changes still need implementation.
